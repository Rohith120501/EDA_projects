# EDA Projects

A collection of Exploratory Data Analysis (EDA) projects in Python. 

The goal of this repository is to analyze datasets, clean data, create visualizations, and find insights.

---

## 📌 What I Did in These Projects

* **Data Cleaning:** Handled missing values, removed duplicate entries, and fixed incorrect data types.
* **Data Preprocessing:** Handled outliers and formatted features for better analysis.
* **Univariate Analysis:** Explored individual variables using histograms, count plots, and box plots to understand distributions.
* **Bivariate & Multivariate Analysis:** Analyzed relationships between features using scatter plots, bar charts, and correlation heatmaps.
* **Insights:** Extracted key observations and patterns from the data to draw meaningful conclusions.

---

## 📁 Repository Contents

* `notebooks/` - Jupyter notebooks with step-by-step data analysis.
* `datasets/` - CSV files used in the projects.

---

## 🛠️ Tools & Libraries Used

* Python
* Pandas & NumPy (Data handling)
* Matplotlib & Seaborn (Data visualization)
* Jupyter Notebook
