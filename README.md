# EDA Projects

A collection of Exploratory Data Analysis (EDA) projects in Python. 

The goal of this repository is to analyze datasets, clean data, create visualizations, and find insights.

---

## 📁 Repository Contents

* `notebooks/` - Jupyter notebooks with step-by-step data analysis.
* `datasets/` - CSV files used in the projects.

---

## 🛠️ Tools & Libraries Used

* Python
* Pandas & NumPy (Data handling)
* Matplotlib & Seaborn (Data visualization)
* Jupyter Notebook
